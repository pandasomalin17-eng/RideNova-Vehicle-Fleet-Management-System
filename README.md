# RideNova - Vehicle & Fleet Management System

## Project Overview

RideNova is a Salesforce Admin project developed to manage vehicles, bookings, payments, maintenance, customer feedback, and support tickets in one place.

This project demonstrates the use of Salesforce Administration features such as Custom Objects, Validation Rules, Record-Triggered Flows, Reports, Dashboards, and Lightning App Builder.

---

## Features

- Vehicle Management
- Booking Management
- Payment Tracking
- Vehicle Maintenance Records
- Driver Assignment
- Vehicle Inspection
- Customer Feedback
- Support Ticket Management
- Reports and Dashboards
- Automation using Record-Triggered Flows

---
